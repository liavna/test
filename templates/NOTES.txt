============================================================
🎯 DEMO QUICK START
============================================================

1. Open the Speech.AI UI in your browser

2. Enable "🎭 Demo Mode" to see a simulated Greek conversation
   (Works without microphone - perfect for presentations!)

3. Or configure real endpoints:
   - Whisper/STT Endpoint: Your MLIS Whisper URL
   - Qwen/LLM Endpoint: Your MLIS Qwen URL  
   - MLIS API Token: Your authentication token

4. Click "🔌 Connect & Detect Models" to discover available models

5. Record or upload audio and click "🚀 Process Audio"

🇬🇷 GREEK DEMO FEATURES

🔧 USEFUL COMMANDS
============================================================

# Check pod status
kubectl get pods -l app={{ .Values.appName }} -n {{ .Release.Namespace }}

# View logs
kubectl logs -l app={{ .Values.appName }} -n {{ .Release.Namespace }} -c {{ .Values.appName }} -f

# Check service
kubectl get svc {{ .Values.appName }}-service -n {{ .Release.Namespace }}

{{- if .Values.ezua.enabled }}
# Check VirtualService
kubectl get virtualservice {{ .Values.appName }}-vs -n {{ .Release.Namespace }}

# Verify endpoint
kubectl get virtualservice {{ .Values.appName }}-vs -n {{ .Release.Namespace }} -o jsonpath='{.spec.hosts[0]}'
{{- end }}

# Port-forward for local testing
kubectl port-forward svc/{{ .Values.appName }}-service 8501:8501 -n {{ .Release.Namespace }}
